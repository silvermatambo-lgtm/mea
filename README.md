# Tourism Current — Mbango Eco Adventure

Mobile-first installable PWA learning demo for South African tourism studies. Designed from the supplied MEA Tourism Current poster and UltraMax 7.2 brief.

## Functions
- Tourism stories with category filters and classroom case-study pages
- CAPS-related links for grades 10–12 (illustrative, subject to educator review)
- Careers, responsive 3D flip cards, scroll reveal animation
- Interactive five-question quiz with explanations
- Printable/downloadable case study worksheets
- Local story authoring with browser storage
- Offline app shell, manifest and service worker, mobile bottom navigation

## Important limitation
This is a **prototype**, not a public multi-school CMS. Local authored stories stay on the same browser. Connect a database, authentication, school roles, content moderation and file storage to enable shared school-wide publishing. Uploaded files are not supported yet. Sample educational stories are clearly marked as illustrative.

## Deployment
Static root site. Vercel project framework: Other; output directory blank. Git repository: silvermatambo-lgtm/mea.
